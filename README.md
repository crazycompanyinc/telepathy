## What is Telepathy?

Telepathy provides real-time workspace awareness for AI agents. It gives every agent a live radar screen showing what all other agents are doing, what tools they're using, and what events are happening — enabling true multi-agent collaboration.

## ✨ Features

- 📡 **Live Radar** — real-time view of all agent activities
- 🔔 **Event Stream** — WebSocket-based live updates
- 🗺️ **Workspace Map** — visual representation of agent topology
- 💬 **Agent Chat** — direct communication between agents
- 📊 **Activity Feed** — chronological log of all actions
- 🎯 **Focus Mode** — filter by agent, tool, or event type
- 🔍 **Search** — find past events and interactions

## 🚀 Quick Start

```bash
git clone https://github.com/crazycompanyinc/telepathy
cd telepathy
npm install
npm run dev
```

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Real-Time:** WebSockets, Server-Sent Events
- **Backend:** Node.js, Express
